Practical Prompt Engineering assignment covering Zero-Shot, One-Shot, and Few-Shot prompting.
Prompt Engineering – Practical Assignment

Overview

This repository contains my practical assignment for the Prompt Engineering Hands-on course at Tayana Academy.

The assignment covers three important prompt techniques:

Zero-Shot Prompting – asking AI to perform a task without providing examples.

One-Shot Prompting – providing one example to guide the AI.

Few-Shot Prompting – providing multiple examples to establish a pattern, style, or format.

Assignment Exercises

Exercise 1 – Identify the Prompt Technique

Identifies a direct task with no examples as Zero-Shot Prompting.

Exercise 2 – Prompt Recognition

Identifies a prompt containing one example as One-Shot Prompting.

Exercise 3 – Choose the Correct Technique

Selects Few-Shot Prompting when multiple examples are useful for maintaining a consistent writing style.

Exercise 4 – One-Shot Prompt Creation

Creates a customer-support prompt containing exactly one example to guide a polite and professional response.

Exercise 5 – Rewrite Using the Correct Technique

Improves a simple professional-writing prompt by using a One-Shot example.

Exercise 6 – True or False

Explains why the statement about Few-Shot Prompting being used for simple tasks is False.

Exercise 7 – Prompt Comparison

Compares two prompts and explains why the more specific prompt produces a more focused result.

Exercise 8 – Technique Selection

Selects Few-Shot Prompting for consistent writing style across multiple outputs.

Exercise 9 – Bonus Challenge

Summarizes the difference between Zero-Shot, One-Shot, and Few-Shot Prompting.

Good prompts reduce ambiguity and clearly communicate the user's intent. Choosing the right prompting technique can improve the relevance, consistency, and quality of AI-generated responses.
